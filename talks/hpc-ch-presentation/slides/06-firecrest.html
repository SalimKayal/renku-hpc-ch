Talking to SLURM: FirecREST

  • REST gateway to HPC, built by CSCS
  • OIDC auth — identity managed by Renku through an integration
  • Submit jobs, poll status, move files — over HTTPS
  • No SSH keys, no bastion hosts to manage

Renku's remote-session-controller generates the session_script.sh + environment.toml and submits via FirecREST.
