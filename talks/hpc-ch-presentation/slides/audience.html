Intended Audience

  • ✔ Cloud-first users who want HPC access without learning complex batch systems
  • ✔ Project leads who need to share projects between cloud and HPC collaborators
  • ✔ HPC newcomers who find traditional HPC systems intimidating
  • ✘ Not for power users: daily HPC users should stick to native tools
  • ✔ Key benefit: one project, two interfaces for different skill levels
