One image,
two worlds

  • Define env in Git: environment.yml, requirements.txt, pyproject.toml
  • Buildpacks + Shipwright produce an OCI image
  • On HPC: Pyxis + Enroot pull the same image
  • No Docker daemon, no root, plays nicely with SLURM
